Deine Lizenzschlüssel für digitale Schulbücher bekommst du in **GGS Media** unter **Meine Lizenzen**. Dort holst du jeden Schlüssel ab und löst ihn danach im Bildungslogin ein. Wie das Einlösen geht, steht in [Digitale Schulbücher im Bildungslogin nutzen](/schulalltag/bildungslogin).

## Das brauchst du

- Dein **Schulkonto**, also dieselben Daten wie für Teams

## Lizenzschlüssel abrufen

1. Öffne [Meine Lizenzen](https://media.ggs.nrw/my-licenses).
2. Klicke auf **Login with Microsoft** und melde dich mit deinem Schulkonto an.
3. Du siehst für jedes Buch eine Karte. Tippe bei einem Buch auf **Zum Anzeigen antippen**.
4. Dein Schlüssel erscheint unter **Dein Code** und ist schon in die Zwischenablage kopiert.
5. Löse ihn im Bildungslogin ein. Den Knopf **Bildungslogin öffnen** findest du oben auf der Seite.
6. Komm zurück und mach mit dem nächsten Buch weiter.

![Meine Lizenzen auf dem Handy: ein Buch zum Abrufen, zwei abgerufene Codes und ein verfallener Platz mit dem Knopf Neu anfordern](/images/anleitungen/ggs-media/meine-lizenzen.webp)

Einen abgerufenen Schlüssel kannst du jederzeit wieder anzeigen. Tippe einfach auf den Code, dann wird er erneut kopiert.

> **Wichtig:** Ruf deine Schlüssel bald ab. Ein Platz ist nur eine begrenzte Zeit für dich reserviert, meistens 42 Tage. Wie viele Tage dir noch bleiben, steht unter der Karte.

Steht bei einem Buch **Einlösen bei …** (zum Beispiel bei Anton), löst du den Code nicht im Bildungslogin ein, sondern auf der genannten Seite.

## Was bedeutet was?

| Auf der Karte steht | Bedeutung |
|---|---|
| **Code abrufen** · Platz reserviert, … Tage übrig | Ein Buch ist für dich reserviert. Tippe darauf, um den Code zu bekommen. |
| **Dein Code** · kopiert am … | Du hast den Code schon abgerufen. Er gehört jetzt dir. |
| **Platz verfallen** · nicht rechtzeitig abgerufen | Du hast den Code nicht rechtzeitig abgerufen, und der Platz ist an den Pool zurückgegangen. |
| **Abgelaufen** | Die Lizenz galt nur bis zum Ende des Schuljahres. Du findest sie unter **Abgelaufene anzeigen**. |
| bis … / dauerhaft | So lange gilt der Platz |
| über Regel … / manuell zugewiesen | Woher das Buch kommt: über deinen Kurs oder von der Medienverwaltung |

## Platz verfallen? Neu anfordern

1. Tippe auf der Karte auf **Neu anfordern**.
2. Ist das geklappt, erscheint die Karte wieder mit **Zum Anzeigen antippen**. Ruf den Code jetzt gleich ab.

Ein verfallener Platz kommt nicht von allein zurück, du musst ihn selbst neu anfordern. Das klappt, solange dein Kurs das Buch noch bekommt und Schlüssel frei sind. Sonst erscheint ein Hinweis. Dann schreib der Medienverwaltung oder dem IT-Support.

## Klappt nicht?

- **Kein Buch zu sehen?** Deine Bücher erscheinen, sobald dein Kurs oder die Medienverwaltung sie dir zugewiesen hat. Neue Kursmitglieder werden über Nacht versorgt – schau am nächsten Tag noch einmal nach.
- **„Kein freier Code mehr im Pool"?** Im Moment sind alle Schlüssel vergeben. Wende dich an die Medienverwaltung.
- **Der Bildungslogin nimmt den Code nicht an?** Schreib dem IT-Support, welches Buch es ist. Die Medienverwaltung kann dir einen neuen Code zuteilen; er erscheint dann direkt auf deiner Karte.
- **Immer noch nicht?** Schreib dem IT-Support im Teams-Chat **IT-Support** oder an [support@goethe-gymnasium-stolberg.de](mailto:support@goethe-gymnasium-stolberg.de).
